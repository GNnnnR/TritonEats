# TritonEats

> ## 🌐 Live Demo
>
> **Check out our website:** [TritonEats](https://gnnnnr.github.io/TritonEats/)
TritonEats is a UCSD dining hall review website designed to help students discover better food options on campus. The website organizes UCSD dining halls, introduces restaurants inside each dining hall, allows users to submit ratings, and displays popular food choices based on student feedback.

## Project Overview
UCSD has many dining halls and restaurants across campus, but students may not always know which locations or menu items are worth trying. TritonEats helps solve this problem by providing a centralized place where Tritons can explore dining halls, view restaurant information, and share food ratings.

## Features

- Browse UCSD dining halls and restaurants
- View dining hall locations and menu links
- Expand dining hall cards to see restaurants inside
- Submit ratings for restaurants and food items
- Interactive star rating system
- Top rated food section
- Responsive layout using Flexbox
- Clean navigation bar for moving between sections

## Website Sections

### Home

The home section introduces TritonEats and includes quick navigation buttons for exploring dining halls and submitting ratings.

### About Us

This section explains the purpose of TritonEats and how it helps UCSD students make better dining choices.

### Dining Halls

This section lists UCSD dining halls, including descriptions, images, locations, restaurant details, and rating options.

### Rate Restaurants

Users can submit their own dining experience by selecting a dining hall, rating a restaurant or food item, and writing a review.

### Top Rated Food

This section highlights popular or highly rated food choices based on student reviews.

### Resources

This section provides helpful UCSD dining-related links and information.

## Technologies Used

- HTML
- CSS
- JavaScript
- Flexbox
- Supabase / database integration planned for storing reviews and updating ratings dynamically
